# 当前自定义主题留在旧设置键，其余主题另存新键

汐岛支持保存多个自定义主题后，当前自定义主题（正在使用的，或切回“汐岛”前最后使用的那个）仍存在原有的 `customTheme` 设置里，是否使用它仍由 `customThemeEnabled` 表示；其余主题和当前主题在列表中的位置存在一个新的设置键里。只认识单个主题的旧版本因此照常显示当前主题；它不读写新键，其余主题原样留着。

这样做是因为设置按键分行存储，旧版本只读写自己认识的键，也不会删除不认识的行；用户手动装回旧版本时，外观不应无故变回“汐岛”，已保存的主题也不应丢失。每个主题只存一份，所以旧版本对 `customTheme` 的修改回到新版本后直接就是当前主题的内容，不需要判断两份副本以哪份为准。

## Considered Options

- **全部主题放新键，`customTheme` 保留一份当前主题的副本**：旧版本同样能显示当前主题，但同一个主题有两份，旧版本改过副本后须另定以哪份为准。
- **全部主题放新键，停用 `customTheme`**：存法最直接，但旧版本读不到任何自定义主题，装回旧版本后外观回到“汐岛”。

## Consequences

- 切换当前主题是一次交换：原当前主题移入新键，被选中的主题移入 `customTheme`，两个键须在同一次设置写入中更新。
- 列表顺序不能只靠新键里的数组表达，须同时记下当前主题所在的位置。
- 旧版本导入主题文件会覆盖 `customTheme`，回到新版本后表现为当前主题被替换；这是旧版本已有的行为。
- 个人数据导出文件随设置带走这两个键，新键与 `customTheme` 归同一类，导入时一起替换。
