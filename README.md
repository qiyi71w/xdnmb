## 功能

- **多标签阅读**：每个标签有独立的前进后退，可分栏或整页阅读，重启后恢复标签和阅读位置。
- **串阅读**：在“全部”和“只看 PO”之间切换，两种模式分别记住阅读位置，滚到底部自动加载下一页。
- **引用**：悬停预览，单击跳转，“返回引用处”回到原位。
- **图片**：在应用内缩放、拖动、保存或复制原图。
  原图显示后，用工具栏“复制图片”、Ctrl+C 或在图片上右键复制。静态图复制完整原图，保留透明部分，不按窗口裁切；动图按原文件复制，保留全部帧，粘贴到其他软件时可能作为文件附件出现。复制后关闭查看器或清理缓存不影响粘贴。
  Windows 样本测试中，QQ、微信均以图片接收静态图和完整长图，两帧动图在输入预览中正常播放；QQ 透明显示正常，微信透明度未确认。Apple Silicon Mac 也已完成两软件三类样本的人工复制／粘贴检查，得到整体通过反馈，未逐项记录透明效果或接收形态。Intel Mac 及实际发送后的显示尚未验证。
- **发串与回复**：浮动编辑器，自动存草稿，支持附图、水印和自定义颜文字。
- **多饼干**：导入官网导出的饼干或 userhash，也可登录官网后选择导入；浏览、发言、网页同步可各用一块饼干。
- **订阅**：管理 App UUID 订阅和网页订阅，并在两端之间同步。
- **提醒**：每个串可单独开启“全串更新”“PO 追更”“引用我的发言”，后台检查并发系统通知。
  全串／PO 提醒会排除本机已确认、且能从现有页面证明计数位置的回复；长串、删除留下的缺口或确认较晚时，仍可能提醒自己的回复。不会为此扫描整串，也不会按饼干 ID 抵扣其他客户端的发言。
- **离线保存**：把整串文字和原图存到本机，断网也能看。
- **搜索**：本机搜索已读过的内容，或选择 [XDS](https://xds.wol.moe/)／[nmb-search](https://nmb-search.166666666.xyz/) 联网搜索；也可独立按串号打开。
- **屏蔽与饼干颜色**：在本机屏蔽串号或饼干，给饼干 ID 选颜色。
- **外观**：浅色、深色、跟随系统或自定义主题；正文字体、字号、阅读宽度、密度和界面缩放可调。

## 订阅

- **列表刷新**：每次打开或回到订阅页、切换 App／网页时，先显示上次读完的完整列表，同时在后台读取新一轮；读到结束页后才整体替换。读取失败或中途停止时保留旧列表，并注明它的读取时间。还没有完整列表时逐页显示已读到的部分，并注明尚未读完。
- **读取不随页面中断**：离开订阅页或切到其他串，正在进行的读取会继续。读取中可点“停止读取”，已读到的内容保留。不定时轮询，失败也不自动重试，可用刷新按钮手动再读。其他客户端增删的订阅，要等下一轮读完才会反映。
- **串内订阅状态**：App 和网页分别判断。既没有完整列表、已读到的部分也没有这个串时，按钮显示“读取状态”，点按会读取该端的订阅列表，不会把未知当成未订阅。
- **结果未确认**：加入或取消后若无法确认结果，可点“核对订阅”。核对只读取原来那个 App UUID 或网页饼干的订阅列表，不会重发；提示会写明本次回读的结果：看到了这个串、读取失败、没读完，或读完了也没有。
- **关闭提示**：不想再核对时，点提示旁的 × 关闭；在串内则从订阅按钮旁的下拉菜单关闭。关闭只记录在本机，不修改远端订阅，也不代表已订阅或未订阅，之后可以重新加入或取消。写入或核对进行中不能关闭；关闭没能保存时，提示会保留。

## 饼干颜色

- **添加**：在“设置 › 浏览 › 饼干颜色”输入饼干 ID 后点“添加”，不用先选颜色。新条目用“默认”，即当前主题里普通饼干 ID 的文字颜色，浅色和深色主题下各自不同，不是固定的蓝色。再次添加列表里已有的 ID 不会改动它的颜色和位置。
- **改色**：列表每行、以及发言或串行右键的“饼干颜色…”都提供“默认”和 8 种颜色。改回“默认”后条目仍在列表中；只有点该行的“删除”才会移出列表。
- **导入的饼干**：导入饼干时，它的饼干 ID 自动标为蓝色，每个 ID 只标一次；之后改成别的颜色、改回默认或删除，都不会再被自动改回蓝色。手动添加的 ID 保持默认，重启或升级后也不会变成蓝色。
- 管理员的饼干 ID 固定为红色，不能标色。颜色只保存在本机，只改变饼干 ID 的显示；搜索结果不显示饼干 ID。

## 搜索与串号

- 搜索页默认“本机”；联网侧首次使用 XDS，手动选择会保存在本机。每个搜索页分别保留两渠道的查询、结果与分页；切换渠道不会发送请求。本机筛选不作用于联网查询。
- 联网渠道切换紧跟在“本机｜联网”的“联网”右侧；“按串号打开”常驻顶部，宽窗时紧凑排列在右侧，窄窗时换行。窗口较矮或放大界面后，可滚动访问输入框及错误提示。
- 本机与联网共用搜索框样式。XDS 的“筛选”提供版面、起止日期、主帖／回复、排序、分词／连续出现，以及串正文／整串联合匹配；联合匹配可选择多个词全部命中、任一命中或自动。nmb-search 暂不提供筛选控件。
- 修改或恢复默认筛选只改变当前搜索页的条件，点击“搜索”才生效；翻页、失败重试及“重新搜索”沿用该次已提交的条件。切换渠道保留各自现场，不将本机或 XDS 条件套到 nmb-search。日期不完整或开始晚于结束时，需改正或清空后再搜索。
- 联网只在提交查询、翻页或主动重试时请求，不预取、不自动重试，也不在失败时换到另一服务。已取得的页面可来回查看；XDS 使用页码，nmb-search 的下一页令牌过期或丢失后需要重新搜索。服务失败保留已有结果；有重试时间的限流不会因切换渠道而解除。
- “按串号打开”独立于关键词搜索，接受 1–20 位正整数、`No.1234567`、`>>No.1234567` 与论坛串链接，保留链接里的页码和回复线索。关键词框里的数字仍是搜索词。
- 不知道所属串时，可主动把串号交给 XDS 反查；不会在悬停时自动反查，也不会改变搜索渠道。反查只提供所属串线索：没有核实回复位置时可明确打开原串，不会扫描整串猜页码。失败不新增空标签或后退记录。离开搜索页会取消进行中的定位、反查、打开原串和预览；再后退回到该页时，迟到的结果不会继续读取、跳转或新开标签，需要重新提交。
- 正文、引用卡与版规／说明里的 `No.` 与明确引用一样支持预览、跳转和返回。裸数字不自动链接；选中完整有效串号后，可从右键菜单（键盘可用菜单键或 Shift+F10）预览或打开。普通 `No.` 和裸数字不计入“引用我的发言”提醒。


## 安装

从 [Releases](https://github.com/qiyi71w/xdnmb/releases/latest) 下载对应的安装包：

| 系统 | 文件 |
| --- | --- |
| Windows 10／11 x64 | `xidao-<版本>-win-x64.exe` |
| macOS 13+，Apple Silicon | `xidao-<版本>-mac-arm64.dmg` |
| macOS 13+，Intel | `xidao-<版本>-mac-x64.dmg` |

**macOS**：打开 DMG，把“汐岛”拖进“应用程序”。

> [!NOTE]
> 首次打开若被系统阻止，到“系统设置 › 隐私与安全性”允许打开。更换版本后钥匙串可能再次请求授权，选择允许即可。

### 更新

在“设置 › 系统 › 关于”检查更新。

- **Windows**：下载完成后选择“安装并重启”，或开启“退出时自动安装更新”。
- **macOS**：下载 DMG 后，先退出汐岛，再把新版拖进“应用程序”覆盖旧版。

## 快捷键

macOS 上用 Cmd 代替 Ctrl。

| 操作 | 快捷键 |
| --- | --- |
| 新标签／关闭标签 | Ctrl+T／Ctrl+W |
| 切换标签 | Ctrl+Tab／Ctrl+Shift+Tab（macOS 为 Control） |
| 后退／前进 | Alt+←／Alt+→（macOS 为 Cmd+[／Cmd+]） |
| 刷新当前内容 | Ctrl+R |
| 串内搜索／本机搜索 | Ctrl+F／Ctrl+Shift+F |
| 发送 | 编辑器内 Ctrl+Enter |
| 保存草稿 | Ctrl+S |
| 打开设置 | Ctrl+, |
| 放大／缩小／还原界面 | Ctrl+=／Ctrl+-／Ctrl+0 |

## 数据与隐私

数据都保存在本机，升级和卸载不会删除：

- Windows：`%APPDATA%\汐岛`
- macOS：`~/Library/Application Support/汐岛`

饼干和 App UUID 用系统凭据保护加密（Windows DPAPI，macOS 钥匙串）。联网查询会交给所选的 XDS 或 nmb-search 及其上游，主动所属串反查会把串号交给 XDS；请求不携带论坛饼干凭据、官网会话或 App UUID。第三方收录可能不完整或过时。“打开搜索网站”只会外开当前渠道，不是自动备用服务。浏览缓存默认上限 2 GB，可在“设置 › 存储与缓存”调整或清理。
